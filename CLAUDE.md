# ayushbhattacharya.com

Personal site for Ayush Bhattacharya, founder of Aika Labs. One static page, no build step: everything (markup, CSS, JS) lives in `index.html`. Pushing `main` deploys through GitHub Pages in about a minute.

## How the page works

The page scrolls as a sequence of painted **scenes** with torn-paper **strips** sliding over them:

1. Hero scene (beach with piano) → strip I (Aika)
2. Phone scene → strip II (family: wife, Mabel, Rolf)
3. Home scene (`.scene.still`) → strip III (learning)
4. Coast scene → **paper trail**: career parchments (`.pp`) tossed onto blue felt
5. Writing strip (Aika Labs blog posts) → vermilion CTA strip with footer

- **Scenes** are `position: sticky` panels. `frame()` in the inline script zooms and drifts each painting by scroll progress. `data-zoom`, `data-pan` and `data-drift="0"` tune it per scene.
- **Strips** overlap the scenes through negative margins. Their torn edges are clip-path polygons generated by `tear()` from a seeded random, so they look the same on every load.
- **Parchments** are tossed in when `.papers` scrolls into view (the `tossed` class, then `settled`).
- **Popup content:** clicking a parchment opens the popup with `<template id="d-<data-d>">`. Each template holds the full story of one role.
- **Smooth scrolling** comes from Lenis, loaded from unpkg. Drifting dust is a fixed `<canvas>`.

## Owner's taste

These preferences were set by Ayush, sometimes after a rejected version. Keep new work inside them:

- **Palette:** blue with vermilion as the single warm accent; cream paper.
- **Fonts:** EB Garamond for display, DM Sans for body, Google Sans Code for labels.
- **Plain styling:** upright headings, flat colour and plain blue backgrounds. Ayush reads italic accent words, gradient text, glows, wax stamps and decorative construction lines as AI-generated filler.
- **Art:** realistic 19th-century oil paintings, blue-dominant, with no people and no picture frames. Ayush is a beach person, so use coasts and sea, not mountains.
- **Ayush himself** does not appear in the art or as a photo.
- **Mabel** is a petite, very pale cream golden retriever with a fluffy white plumed tail. **Rolf**, a brown chow chow who has passed away, appears as a portrait on the wall.
- **Copy:** first person, plain, factual. Every claim about his career comes from him; when a detail is missing, ask rather than infer.

## Paintings

Paintings are generated with Gemini 3 Pro Image through treg: endpoint `reapi.image-gen.gemini-3-pro-image`, 16:9 at 2K, about $0.03 each. Reference photos go up with `treg host <file>`. Crop people out of personal photos before hosting.

Each painting ships as:

- WebP at 720, 1280 and 1920 px wide: `assets/art/<name>-<w>.webp`, served through `<picture>`/`srcset`.
- A 32×18 blurred WebP placeholder inlined as the `.art` element's `background-image` data URI. Regenerate it whenever the painting changes.
- For the home scene, a portrait version `home-tall-*` for screens taller than 4:5, so Mabel and Rolf both stay in frame on phones.
- For the hero, `hero-og.jpg`, used as the link-preview image.

Originals are kept on the owner's machine in `~/Desktop/site-paintings`.

## Gotchas

- **Horizontal overflow:** use `overflow-x: clip` on `body` and sections, never `hidden`. `hidden` turns `body` into its own scroll container and breaks both sticky scenes and Lenis.
- **Paintings show unconditionally:** keep scene images visible from first paint over their placeholder. Hiding them until a `load` event left mobile Safari stuck on the blurry placeholder.
- **Triggers:** fire the parchment toss from the scroll-position check in `deal()`. An IntersectionObserver version never fired on some loads.
- **Per-frame work:** `frame()` only runs when `scrollY` changes. Keep transforms off the large filtered paper sheets.
- **Phone overrides:** the mobile media query resets `.strip` margins, so overlap fixes for one section (`.writing`, `.cta`) need their own mobile rule.
- **Domain:** the `CNAME` file and the custom domain are managed by GitHub Pages. Re-setting the domain through the API commits a delete and a re-create of `CNAME` on `main`; run `git pull` afterwards.

## Verifying a change

- **Phone layout:** render with headless Chrome. Load `index.html` inside a 390×844 iframe served from the **same origin**, scroll the iframe to the section, and pass `--force-prefers-reduced-motion` to freeze the motion.
- **Motion and clicks:** check in real Chrome. Lenis animates programmatic scrolls, so wait about 2s before reading positions.
- **Preview server:** serve locally on a free port you have checked with `lsof -i:<port>`, and stop it by the PID you started. Port 8765 belongs to the owner's `io.aika.tunnel-serve` launchd service.
